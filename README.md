## 🚀 Instrucciones de Instalación y Ejecución Local (Backend)

Sigue estos pasos para configurar y ejecutar el servidor en tu entorno de desarrollo local:

### Requisitos Previos
Asegúrate de tener instalado [Node.js](https://nodejs.org/) en tu sistema.


### Clonar el Repositorio e Instalar Dependencias
git clone https://github.com/Tommas138/TPExpress

# Ingresar al directorio del proyecto
cd TPExpress

# Instalar las dependencias de Node
npm install


# Configurar las variables de entorno
1- Crear un archivo llamado .env en la raiz del directorio.

2- Copiar la estructura del archivo readme.md.

3- Solicitar las credenciales reales de la base de datos (DATABASE_URL) por privado al equipo.


# Ejecutar migraciones y seed
1- npx prisma migrate dev

2- npx prisma db seed


# Iniciar el servidor de desarrollo:
npm run dev
